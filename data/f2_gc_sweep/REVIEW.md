## 0. 口径（必须随结果一起报）

1. **基因组**：GTDB **R232**（任务文档写 R226，本机只有 R232 metadata，属代用，已注明）。
   18 个 NCBI 组装、≤5 contigs、checkm2 完整度 ≥98%、污染 ≤1%，GC 从 FASTA 实测
   （与 GTDB 值一致）。每属 1–2 个 spanning 25.4 / 26.1 / 30.6 / 33.0–33.5 / 43.5 /
   50.7–50.8 / 57.0 / 61.5 / 65.3 / 66.0–66.1 / 72.0。
2. **reads 为自模拟**（`scripts/f2_10_simreads.py`）：文档指名的
   `python/sk2bgrow/simulate.py` 是 count 级蒙特卡洛（无 reads、无 CLI），
   故按文档第二选项自建 read 模拟器，模型与其 parity：150 bp 单端、无测序错误、
   GC 中性、50% 反向互补；复制梯度 log2 copy(p) = −log2PTR·dist(p,ori)/(L/2)，
   ori 植在 L/2；深度 d = 终点端**均值 per-base 深度**（0.5/1/2/5×）；
   起点按 copy 加权多项式抽样（= 条件化非齐次 Poisson，自带 shot noise）。
   planted log2PTR ∈ {0.5, 1.0, 1.5, 2.0} × 2 seed 重复 → 每 (基因组, 模式, 深度)
   n=8 对 (估计, 真值)。
3. **stats parity 沿用 F1**：酶臂带 `--windows`（C1 parity），FMH 臂不带
   （armE parity）；FMH 臂 `--db` 用同一基因组的 k16 索引（仅取参考元数据）。
4. **匹配 scale 按各基因组实际密度重新计算**：scale_k = round(L / n_anchors_k)，
   FMH 只跑 k8/k16 两个匹配档；匹配后 FMH 与 panel 密度差 ≤4%（多数 ≤2%）。
5. **混杂警告**：低 GC 端两个 Buchnera 基因组仅 0.65 Mb（25 kb 窗只有 ~26 个），
   低 GC 与**小基因组** confound，无法在本设计内拆开（见 §4 未决）。
6. 跨体制比较无效：F2 的 E. coli k16 0.5× r=0.984 与 F1 的 A_k16 0.568
   （C8 harness）不同体制（模拟 reads+planted truth vs 真实 reads+16 media），
   不能互引；F2 内部比较均为同体制。

- **低 GC（≤30%）+ 0.5× 是所有模式的失效区**（r 最低 −0.5，RMSE 0.6–0.9），
  ≥1× 恢复到 r≈0.8–0.9；这是成立负面，给出仪器边界。
- **k8 无特异性崩溃**：除 Buchnera 外，k8 与 k16 的 r/RMSE 在所有 GC 上

- **FMH 在匹配密度下与 panel 全 GC 打平**（25–35% 带甚至略好，0.5× r 中位

- 0.5× 全 GC 普遍 slope<1（衰减 0.3–0.9），低 GC 更差；系统性低估
  在 ≥1× 基本消失。
- 27 个拟合失败（0.8%）集中于 Buchnera 0.5–1× —— 无 F1 sketch 臂那种
  批量丢 cell，多 strata 融合冗余在 GC 极端依然有效。

## 3. 对 A6 的回答

**A6 的"8 酶够用"在 E. coli 之外成立**：k8 相对 k16 的退化没有在任何 GC
点上达到逆转结论的程度；72% 高 GC 的 k8 密度塌陷（0.64×）不造成精度损失。
A6 可照旧 ship 8，但需附带：(a) GC ≤30% 时即使 16 酶也在 0.5× 失效——
默认 panel 大小救不了低 GC，这是仪器边界不是 panel 尺寸问题；
(b) 若应用关心 GC>70% 且未来窗口更窄/读更短，k16 的密度冗余才有意义。

## 4. 结论分类

**可写论文（正面）**
1. 酶板密度-GC 曲线首次在 18 个真实基因组上实测：单调上升、低 GC 端 ~2×
   depressed、高 GC 端无塌陷；替换 §1.3 的三基因组外推。
2. 匹配密度 FMH 在全 GC（25–72%）与酶板打平，F1 结论推广出 E. coli。
3. A6 跨 GC 复核：8 酶建议在全 GC 范围成立（附边界条件）。

**成立负面**
1. GC ≤30%（且基因组 ≤0.7 Mb）时 0.5× 深度下所有 landmark 模式失效
   （r<0.7、RMSE>0.6）→ 论文可声明的仪器范围是 **GC ≳30%、深度 ≳1×**，
   当前不能声称"GC 25–75% 均匀可用"。

**未决**
1. Buchnera 失效是低 GC 还是小基因组（26 窗）混杂——需"低 GC + 大基因组"
   对照（自然界罕见，可用合成序列补）。
2. C. jejuni（30.6%）处 k8 r=0.50 vs k16 0.70（0.5×）为单基因组 n=8 信号，
   且 k4/k2 反而更高（0.81–0.83），疑似噪声；需加重复或 ptr 档确认。
3. 0.5× slope 系统性 <1 的衰减机制未拆（融合层收缩？窗 landmark 稀疏？）。
