# 多实例 2×2 交互检验（3 实例 × 16 media = 48 单元）

日期：2026-09-13 ｜ 产物：`bench/repro_check/multiseed/` ｜ 代码状态：`275778f-dirty`（同前）

## 1. 实验设计

- **实例 1** = C1 原有子采样（regen_arm{A,B,E_PE,C}_cells.tsv，双端）；**实例 2/3** = 新子采样，种子 **20260912 / 20260913**。
- 子采样完全沿用 C1 标定（`01_subsample.sh`）：`frac = depth × 4641652 / base_count`（manifest 第 3 列，PE 合计），`seqkit sample -p frac -s <实例种子>`；同一 cell 双端用同一种子 → mate 同步。工具为 **seqkit v2.10.0**（任务述及的 seqtk 在系统不存在；seqkit 即 C1 原用工具，RNG 语义与实例 1 完全一致）。每 cell 确切 read 数与同步校验记录于 `seed<yyy>/fq/*.info.tsv`（85/85 sync=OK ×2 实例；如 SRR11558945 0.5×：7,865/7,865）。
- 五臂管线与实例 1 相同（A：sk2bgrow count+stats --windows；B：同 A +`--method sorted`；E：`armE_counts_pe.py` scale 104 池化双端 + stats 不带 --windows；C：Pilea 1.3.8 default/relaxed）。完成度：A/B/C_relaxed 全 85/85 有估计；E 84/85、82/85（低深度个别格无估计，同实例 1 行为）；C_default 仅 10× 有估计（17/85，gate 行为跨实例一致）。

## 3. 交互检验（配对 cluster bootstrap）

定义：interaction_z = (z_A − z_B) − (z_E − z_C_relaxed)，z 为 Fisher z( Pearson r )；48 单元 = 16 media × 3 实例；**按 medium 配对抽样**（抽中的 medium 带齐 3 个实例），B=10000，bootstrap 种子 20260912。

| cov | z_obs | boot 均值 ± SD | 95% CI | 判定 |
|---|---|---|---|---|
| 0.5× | NA | — | — | C_relaxed 退化（常数 0），不可检验 |
| 1× | −0.038 | −0.050 ± 0.164 | [−0.368, +0.279] | 不显著 |
| **2×** | **−0.494** | **−0.496 ± 0.113** | **[−0.728, −0.278]** | **显著为负**（z_norm=−4.36） |
| 5× | +0.173 | +0.139 ± 0.216 | [−0.347, +0.480] | 不显著 |
| 10× | +0.292 | +0.263 ± 0.335 | [−0.408, +0.867] | 不显著（点估计为正但 CI 宽） |

**逐实例分解**（各实例内 16 单元的 interaction_z）：2× 在三个实例同号（inst1 −0.365 / 20260912 −0.484 / 20260913 −0.674）——负交互跨实例稳健；5×、10× 三实例均为正但量小；1× 符号不一。

## 4. 判定

1. **交互项真实存在，但呈深度依赖形态**：仅 **2× 显著为负**（CI 不含 0，三实例同号）；1×/5×/10× 均不显著。
2. **Mac 旧实例的"1×/2×/10× 正显著"形态不复现**——结合 VERIFY_BC 的结论（B/C 提取无系统偏差），旧形态应归因于 Mac 8/25 实例的统计层代码漂移（B 臂系统性高估被修正后，anchors 上的 estimator 对比收缩），而非真实交互。
3. 2× 负交互的解释：该深度上 V-fit 相对 sorted 类估计器的优势在 sketch landmark（E 0.967 vs C_relaxed 0.842）远大于 anchor（A 0.963 vs B 0.931），即 estimator×landmark 交互在 2× operating point 真实存在——这为论文的 estimator×landmark 章节提供了比旧实例更可靠的证据（48 单元 + 显式 CI）。
4. 0.5× 因 Pilea relaxed 输出退化（PTR=1 常数列）无法进入交互检验；如需 0.5× 的交互证据，须对 C 臂换用非退化的对照（如 C_default 在 10× 以下无估计，亦不可行）——建议论文明确 0.5× 交互不可检验。
5. 局限：3 实例共享同一套 16 个 medium（配对设计的代价）；bootstrap 按 medium 聚类已部分缓解。实例 2/3 与实例 1 的 read 数标定相同但抽样实现为 seqkit 概率抽样（与 C1 相同机制），实例间 reads 独立。
